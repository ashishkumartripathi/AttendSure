# AttendSure

**An Explainable Attendance Integrity and Anomaly Detection System for Rural Schools**

AttendSure is an offline-first prototype designed to help rural school administrators and educators maintain attendance integrity. The system analyzes attendance records, flags unusual patterns using transparent, rule-based criteria, and provides human-interpretable explanations for every alert.

> [!IMPORTANT]
> **Decision Support Philosophy**: Alerts generated by AttendSure are indicators intended solely for human review. They are never treated as automated proof of fraud, negligence, or misconduct.

---

## Prototype Scope

### In-Scope (Current & Planned Prototype)
- **Data Ingestion**: Support synthetic attendance records and manual record entries.
- **Explainable Anomaly Detectors**:
  - *Large Attendance Drops*: Flagging unexpected drops compared against a documented historical baseline.
  - *Repeated Headcounts*: Flagging suspicious patterns where identical class headcounts persist across consecutive sessions.
- **Transparent Explanations**: Every alert provides the triggered rule, observed values, historical baseline, and plain-language explanation.
- **Model Evaluation**: Systematic detector benchmarking on labelled synthetic datasets using Precision, Recall, F1-Score, and Confusion Matrix metrics.
- **Export Capabilities**: CSV export for review summaries, audit trails, and detected anomalies.
- **Offline-First Operation**: All core computation, storage, and visualization run locally without external cloud dependencies.

### Out of Scope (Initial Phase)
- Facial recognition or biometric identity tracking.
- Paid AI APIs or external cloud model endpoints.
- Automated fraud accusations or disciplinary workflows.
- Government portal integrations, parent SMS gateways, cloud database synchronization, and mobile (Android/iOS) apps.
- Unverified claims of end-to-end encryption, tamper-proof storage, or regulatory compliance until formal implementations and audits exist.

## Setup & Development (Planned)

### 1. Prerequisites
- Python 3.13 is the current development target; support for other Python versions will be confirmed only after compatibility testing.
- Git

### 2. Virtual Environment Setup
```bash
# Clone the repository
git clone https://github.com/ashishkumartripathi/AttendSure.git
cd AttendSure

# Create virtual environment
python -m venv .venv

# Activate virtual environment
# On Windows (PowerShell):
.venv\Scripts\Activate.ps1
# On Linux / macOS:
source .venv/bin/activate
```

### 3. Dependency Installation (Future Step)
Dependency installation is a future step until `requirements.txt` or `pyproject.toml` is created. Do not run dependency installation commands yet, as no dependency configuration file exists in the repository at this stage. Once created, dependencies will be installed into the virtual environment (e.g., via `pip install -r requirements.txt`).

### 4. Running the Dashboard (Planned)
```bash
streamlit run src/attendsure/ui/app.py
```
